# Windows design.md

Design family: Windows 11 / Fluent.

## Contract
- Segoe UI Variable, compact desktop density, Mica/acrylic only for chrome or transient surfaces.
- Window content uses restrained 4–8px radii and clear command hierarchy.
- Prefer command bars, tabs, navigation rails and right-side panels; avoid mobile-style large grouped cards.
- Settings use a desktop navigation/tab hierarchy with concise labels and values.
- Modal workflows use centered content dialogs; non-blocking management flows may use side sheets.
- Preserve keyboard focus, pointer hover, resize and snap behavior.
- Accent is functional, not decorative; use neutral surfaces for most content.
