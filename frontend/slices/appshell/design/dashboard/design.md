# Dashboard design.md

MSO cockpit design language (not a fake consumer OS).

## Contract
- Dense operational layout, neutral graphite surfaces, high information density and clear hierarchy.
- Use 8px rhythm, compact cards/tables, restrained radius and strong status/value alignment.
- Prefer inline panels and right-side drawers for configuration/secondary detail.
- Avoid iOS/Material/Fluent signature chrome; Dashboard should read as an operations cockpit.
- Preserve keyboard/pointer workflows and expose system state without decorative duplication.
- Shared feature logic remains identical to every other shell; only the renderer/density changes.
