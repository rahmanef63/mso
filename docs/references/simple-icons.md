## What MSO uses

`lib/infra/provider-icons.ts` embeds SVG path strings for GitHub, Cloudflare,
Hostinger, Vercel and Convex Cloud, taken from Simple Icons. The file header states
the source and the CC0 license, and records that brand trademarks remain with their
owners.

`simple-icons` is also a dev dependency and appears in a `deps-dev` bump entry in
[`../CHANGELOG.md`](../CHANGELOG.md).
